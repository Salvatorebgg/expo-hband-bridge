在 classes.jar 中使用 javap 查看，未运行 SDK：
VPOperateManager:
  public void startScanDevice(com.inuker.bluetooth.library.search.response.SearchResponse);
  public void startScanDevice(int, com.inuker.bluetooth.library.search.response.SearchResponse);
  public void stopScanDevice();

SearchResponse:
  void onSearchStarted();
  void onDeviceFounded(com.inuker.bluetooth.library.search.SearchResult);
  void onSearchStopped();
  void onSearchCanceled();

SearchResult:
  getName(), getAddress(), rssi, scanRecord。
本桥仅复制 name/address/rssi，不导出 scanRecord。

startScanDevice(int, SearchResponse) 的字节码显示：
  输入 int * 1000 -> SearchRequest.Builder.searchBluetoothLeDevice(..., 1)。
协议库内部 VPOperateManager$vp_b.onDeviceFounded 会调用
  VpBleByteUtil.isBeyondVp(scanRecord)
  VpBleByteUtil.isBrandDevice(scanRecord)
  并依据内部标志分支后才转发结果。
因此它确实不是“列出所有 BLE 广播”的无过滤入口；本桥未绕过此机制。
这不能证明特定型号兼容或实际数据可读。
